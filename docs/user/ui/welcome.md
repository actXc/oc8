# Welcome wizard

**Route:** `/welcome` · Shown to new-tenant admins (not a permanent sidebar item)

## What it is

Guided **first-run onboarding**: workspace → department → agent → model → tool →
guardrails → done → Office.

## What it is for

- Avoid an empty product after install
- Teach the minimum path **in the UI** — including model and first tool
- Land you on [Office](office.md) ready to explore

You do **not** need a separate terminal step to connect a model if you complete
this wizard; it includes the [Models](models.md) step.

## Where you are in the flow

```text
Install / first login → ★ Welcome steps → Office (/)
```

## Steps (typical)

1. Workspace / org basics  
2. First [Department](departments.md)  
3. First [Agent](agents.md)  
4. [Model](models.md)  
5. Tool via [Capas](capas.md)  
6. Guardrails / autonomy  
7. Done → Office  

## Where work goes next

After **Done**, use [Office](office.md), run a task, and watch [My work](my-work.md)
if anything needs approval.
