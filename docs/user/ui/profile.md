# Profile

**Route:** `/profile` · Header avatar (not in the sidebar)

## What it is

Your personal account surface — especially **notification preferences** for new
approvals and similar events.

## What it is for

- Enable push / notification channels so My work items do not sit unseen
- Manage personal prefs without changing tenant settings

## Where you are in the flow

```text
You are an operator → ★ Profile (notify me) → My work when something waits
```

## What you do here

1. Open your avatar → Profile.
2. Enable notifications for approvals if offered.
3. Return to [My work](my-work.md) / [Office](office.md).
