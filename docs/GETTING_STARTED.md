# Getting started with oc8

> **Start here:** [User documentation → Quickstart](user/quickstart.md)

## Fastest path

```bash
./scripts/quickstart.sh          # macOS / Linux
# PowerShell on Windows:
./scripts/quickstart.ps1
```

Then open the printed URL, complete setup, configure a model, create an agent,
and run a task.
