# Support policy

## Current status

oc8 is in pre-release development. There is no public support plan, response
time commitment, managed-hosting offering or compatibility guarantee at this
time.

## Self-hosting guidance

Start with [README.md](README.md), then follow the
[Docker Compose deployment guide](docs/DEPLOY.md). The deployment guide
documents the required secrets, local-administrator setup flow, explicit
development/demo override and important security limitations.

The scope and deliberate limitations are summarized in
[docs/SCOPE_AND_LIMITATIONS.md](docs/SCOPE_AND_LIMITATIONS.md).

## Security issues

Do not use a public support channel for suspected vulnerabilities. Follow
[SECURITY.md](SECURITY.md).

## Public participation

[CONTRIBUTING.md](CONTRIBUTING.md) is authoritative: this private development
monorepo is not currently accepting external contributions. A public issue,
discussion and support policy will be published before the repository is
opened for external participation.
