# Code of Conduct

## Our commitment

We want oc8 project spaces to be professional, constructive and welcoming to
people with different backgrounds, identities and experience levels. Everyone
participating in project discussions, reviews, events and other collaboration
spaces is expected to help maintain that environment.

## Expected behavior

- Be respectful, specific and constructive when discussing ideas or code.
- Assume good intent while making room for questions and different experience
  levels.
- Focus criticism on behavior, decisions and work—not personal attributes.
- Protect confidential information, credentials, customer data and security
  reports.
- Respect reasonable boundaries and requests to stop harmful behavior.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, sexualized language or
imagery, deliberate intimidation, doxxing, or sharing private information
without permission are not acceptable. The same applies to deliberately
disruptive conduct and to public disclosure of a suspected vulnerability before
maintainers have had a reasonable opportunity to investigate it.

## Scope

This Code applies in project-controlled collaboration spaces and when someone
is representing oc8 in a public context. It complements, but does not replace,
the security process in [SECURITY.md](SECURITY.md).

## Reporting and enforcement

This pre-release repository does not yet publish a public conduct-reporting
contact. If you are participating under an existing private project agreement,
use the private channel supplied with that agreement. Maintainers must publish a
monitored reporting path before opening external participation.

Maintainers may clarify expectations, request a correction, remove content,
restrict participation or take other proportionate action to protect the
community. No public discussion of a report is required or expected.
